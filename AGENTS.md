# Agent instructions

## Agent skills

### Issue tracker

Issues live in GitHub Issues for blackdragoon26/Moodish, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default roles, each label named after its role: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root, created only when a term or decision is actually settled. See `docs/agents/domain.md`.
